# 맛집공유 (matjip-share) — PRD

> 최종 수정: 2026-08-01
> 상태: 확정 (v1.1 — 지도 플랫폼을 네이버→카카오로 변경)

## 1. 한 줄 요약

친구들끼리 **카카오맵 위에 각자 고유 색상으로 맛집을 찍고, 실시간으로 서로 공유**하는 반응형 웹앱.

## 2. 배경 / 문제

- 네이버 지도·카카오맵의 즐겨찾기(별표)는 **개인 계정에 갇혀 있어** 친구끼리 공유가 안 된다.
- 즐겨찾기는 **공개 API가 없어** 외부 앱이 읽거나 색상을 바꿀 수 없다. → 지도 앱의 기본 즐겨찾기 기능은 사용 불가.
- 그래서 **카카오맵 위에 "우리끼리만의 즐겨찾기 층"을 직접 얹어** 같은 경험을 만든다.

### 지도 플랫폼 결정 (v1.1, 2026-08-01)

- 요구사항: **과금 확률 0** (카드/결제수단 등록 자체를 하지 않음).
- 네이버(NCP)는 카드 등록 필수 + 무료 한도 초과 시 자동 과금 → **탈락**.
- 카카오는 계정당 첫 번째 앱에 **결제수단 등록 없이** 무료 쿼터 제공 (지도 30만 로드/일, 장소검색 10만 건/일 — 2026-07-21 정책 기준). 결제수단 미연결 시 과금 불가, 초과 시 호출 실패만. 6~10명 사용량으로는 사실상 도달 불가 → **채택**.
- 오픈소스(Leaflet+OSM)는 한국 POI·장소 검색 품질 문제로 탈락.

## 3. 목표 / 비목표

### 목표 (MVP)
- 접속하면 **로그인 없이 바로** 지도 사용
- 각 사용자는 **고유 색상**을 부여받고, 자기가 찍은 핀이 그 색으로 표시됨
- 친구가 맛집을 추가하면 **실시간으로** 내 화면에도 나타남
- **하나의 공유 지도**를 모두가 함께 봄

### 비목표 (이번 범위 아님)
- 정식 로그인/회원가입, 비밀번호 관리
- 여러 그룹/여러 지도
- 사진 업로드, 한줄평/댓글, 좋아요·투표
- 추천 알고리즘, 검색 랭킹, 알림

## 4. 타깃 사용자

- 나 + 내 친구들 (사적인 소규모 그룹)
- 예상 규모: **6~10명**
- 기술 이해도 무관, 링크 하나로 접속

## 5. 핵심 사용자 경험

가장 자주 하는 행동: **"지도에서 맛집 찾아 별점 주며 찍기"** + **"친구들이 찍은 곳 둘러보기"**

## 6. 기능 요구사항

### 6.1 사용자 식별 (로그인 없음)
- 첫 접속 시 **이름을 직접 입력** → 자동으로 팔레트에서 **고유 색상 배정**
- 이름↔색상 매핑은 DB에 저장되어 유지됨
- 브라우저(localStorage)가 "나는 OOO" 를 기억 → 재접속 시 다시 안 고름
- **트레이드오프(감수):** 인증이 없으므로 링크를 아는 사람은 누구나 입장 가능, 이름 중복 가능. 친구끼리 쓰는 앱이라 허용.

### 6.2 색상 배정
- 6~10명을 뚜렷이 구분할 수 있는 **고대비 팔레트** 사전 정의
- 새 이름이 들어오면 아직 안 쓰인 색을 순서대로 배정
- 팔레트 소진 시 색 재사용(이름 라벨로 구분 보조)

### 6.3 맛집 핀 (하나당 정보)
- **가게 이름 + 위치(좌표/주소)** — 필수, 장소 검색으로 자동 입력
- **별점(★, 예: 1~5)** — 필수
- (확장 후보: 한줄평/메모, 사진, 방문여부 · 이번 범위 아님)

### 6.4 맛집 추가
- 장소 검색(카카오 로컬 API 키워드 검색) → 결과 선택 → 좌표 확정
- 별점 입력 → 저장 → **내 색상 핀**으로 지도에 즉시 표시

### 6.5 실시간 공유
- 누군가 핀을 추가/수정/삭제하면 **다른 사람 화면에 실시간 반영** (Supabase Realtime)
- 핀은 **작성자 색상**으로 렌더링

### 6.6 편집 권한
- 본인이 찍은 핀만 수정/삭제 가능 (MVP 기준, 강제는 UI 레벨)

## 7. 화면 (MVP)

1. **이름 입력** — 최초 1회 (이후 자동 스킵)
2. **지도 메인** — 카카오맵 + 모든 친구의 색상 핀, 핀 클릭 시 정보(가게명·별점·작성자)
3. **맛집 추가** — 장소 검색 → 별점 → 저장 (메인 위 오버레이/시트로)

## 8. 기술 스택

- **프론트엔드:** Next.js (App Router) + TypeScript + Tailwind CSS
- **지도 표시:** 카카오맵 JavaScript SDK — *무료 30만 로드/일, 결제수단 등록 없음*
- **장소 검색:** 카카오 로컬 API (키워드로 장소 검색) — *같은 앱 키, 무료 10만 건/일*
- **백엔드/DB:** Supabase (Postgres + Realtime)
- **배포:** Vercel (프론트), Supabase (데이터)

## 9. 데이터 모델 (초안)

```
users            (id, name, color, created_at)
                 -- 로그인 없는 "이름 기반" 사용자. name 유니크 권장.

places           (id, user_id, name, address, lat, lng,
                  rating, created_at)
                 -- 하나의 공유 지도이므로 group 개념 없음.
```

- 하나의 공유 지도 → `places`에 group_id 불필요
- Realtime: `places` 테이블 구독으로 추가/수정/삭제 전파
