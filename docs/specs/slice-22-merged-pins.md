# 슬라이스 22: 같은 가게 핀 병합

> 상태: 구현 완료 (단위 85 + E2E 35 통과, 수동 검증 완료)
> 배경: 사용자 질문 — "친구가 A가게를 추가하고 나도 A가게를 추가하면?"
> 기존: 핀이 같은 좌표에 포개져 한 명이 가려짐.

## 동작 규칙

1. **그룹 기준**: 같은 가게 = 이름 + 좌표 동일 (카카오 출처면 자동으로 일치).
2. **핀**: 그룹당 1개. 2명 이상이면 핀 원 안에 **인원수 숫자**, 라벨 칩에 **작성자 색 점들**(최대 3개).
   단독 핀은 기존과 완전히 동일.
3. **카드**: 가게명·주소 1번 + **저장한 전원의 별점·한줄평을 행으로** 표시.
   내 행에만 수정(별점+한줄평)/삭제. 삭제 확인 문구 유지.
4. **나도 별점 남기기**: 내 항목이 없으면 카드 안에서 바로 별점·한줄평 입력 → 저장 (검색 불필요).
5. 목록·필터·실시간·fit bounds는 기존 유지 (그룹은 표시 계층에서만 파생).
