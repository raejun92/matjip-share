# 슬라이스 21: 핀 이름 라벨

> 상태: 구현 중
> 배경: 사용자 피드백 — "핀은 보이는데 무슨 음식점인지는 줌을 당겨야 안다"

## 동작 규칙

1. 각 핀 위에 **가게 이름 칩** 표시 (흰 배경, 최대 폭 말줄임).
2. 라벨은 **줌 레벨 9 이하(시/구 수준 이상 확대)일 때만** 표시 —
   광역 뷰에서 라벨이 겹쳐 지저분해지는 것 방지.
3. 라벨도 핀 버튼의 일부 → 탭 영역이 커지는 부수 효과.
4. 필터·실시간 등 기존 동작 불변.

## 인수 기준

| # | 기준 | 검증 방법 |
|---|------|----------|
| AC1 | 기본 줌에서 핀 위에 가게 이름 표시 | E2E |
| AC2 | 광역 줌(레벨 10+)에선 라벨 숨김 | 수동 (E2E는 줌 제어 불가) |
