# 슬라이스 20: 근접 후보 복수 제안 (같은 건물 문제)

> 상태: 구현 완료 (단위 80 + E2E 34 통과, 홍미관 실좌표로 재현·수정 확인)
> 배경: 실사용 제보 — 홍미관을 탭했는데 꾼들의공연이 제안됨.
> 원인: 두 가게가 같은 건물(좌표 동일, 0m 동률) — 최근접 1곳만 고르면 카카오 반환 순서가 승자를 정함.

## 동작 규칙

1. 탭 지점 30m 내 후보가 **1곳** → 기존처럼 "📍 {이름}" 바로 제안.
2. **2곳 이상** → 가까운 순으로 **최대 3곳을 모두 버튼으로** 표시 — 사용자가 고른다.
   (웹 지도는 어떤 라벨을 탭했는지 알려주지 않으므로 단정하지 않는 것이 정답)
3. 후보 버튼 탭 → 지도 이동 + 별점 화면 직행 (기존 직행 흐름).
4. "주변 더 보기"·✕·빈 곳 동작은 기존 유지.

## 인수 기준

| # | 기준 | 검증 방법 |
|---|------|----------|
| AC1 | 임계값 내 후보를 가까운 순 최대 3곳 반환 (0곳이면 빈 배열) | 단위 (TDD) |
| AC2 | 동률 2곳 지점 탭 → 두 버튼 표시 → 선택한 가게로 별점 진행 | E2E + 수동 |
