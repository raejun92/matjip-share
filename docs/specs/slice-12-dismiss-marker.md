# 슬라이스 12: 임시 마커 재탭으로 지우기

> 상태: 구현 완료 (E2E 21 통과, 수동 검증 완료)
> 배경: 사용자 피드백 — "잘못 클릭해서 생긴 마커를 다시 클릭하면 지워지게 하자"

## 동작 규칙

1. 임시(회색) 마커가 있는 상태에서 **그 마커 근처(화면 30px)를 다시 탭**하면
   마커와 popover가 사라진다 (토글).
2. 마커에서 먼 곳을 탭하면 기존대로 그 자리로 지점 이동.
3. 우선순위: **임시 마커 해제 > 저장된 핀 열기 > 새 지점 선택**
   (회색 마커가 보이는 상태에선 그걸 지우려는 의도가 우선).

## 인수 기준

| # | 기준 | 검증 방법 |
|---|------|----------|
| AC1 | 마커 근처 재탭 → 마커·popover 제거, 다른 흐름 미진입 | E2E |
| AC2 | 마커에서 먼 탭 → 지점 이동 (기존 동작 유지) | E2E (기존 회귀) |

(픽셀 히트 판정은 슬라이스 11의 findNearestWithin 재사용 — 신규 순수 로직 없음)
