# 슬라이스 2: 카카오맵 표시

> 상태: 구현 완료 (단위 25 + E2E 3 통과, 실지도 렌더링 확인)
> PRD 근거: §7 화면 2 (지도 메인), §8 기술 스택 (카카오맵 JavaScript SDK)

## 목표

이름 입력(슬라이스 1)을 마친 사용자에게 **전체 화면 카카오맵**을 보여준다.
지도 위에 **내 이름 + 색상 배지**가 떠 있어 "내가 누구로 접속했는지" 보인다.
이 슬라이스가 끝나면: 환영 화면(placeholder)이 실제 지도 화면으로 교체된다.

## 사용자 스토리

- 나는 이름 입력을 마치면 바로 지도를 볼 수 있다.
- 나는 지도를 자유롭게 이동/확대할 수 있다 (카카오맵 기본 조작).
- 나는 화면 위 배지에서 내 이름과 색을 확인할 수 있다.

## 동작 규칙

1. **SDK 로드**: 카카오맵 JS SDK를 동적으로 로드 (`autoload=false` → `kakao.maps.load`). 키는 `NEXT_PUBLIC_KAKAO_JS_KEY` 환경변수.
2. **초기 위치**: 서울시청 (37.5665, 126.9780), 레벨 5. (다음 슬라이스에서 핀들 기준으로 조정 예정)
3. **배지**: 지도 좌상단에 내 색상 원 + 이름 오버레이.
4. **실패 처리**: SDK 로드 실패(키 오류/네트워크) 시 사용자에게 오류 메시지 표시.

## 인수 기준 (Acceptance Criteria)

| # | 기준 | 검증 방법 |
|---|------|----------|
| AC1 | SDK URL이 키/옵션으로 올바르게 조립된다 | 단위 (TDD) |
| AC2 | 이름 입력 완료 후 지도 화면이 렌더링된다 (kakao.maps 로드 + 지도 타일 표시) | E2E |
| AC3 | 지도 위 배지에 내 이름과 색상이 보인다 | E2E |
| AC4 | 재접속 시에도 바로 지도 화면이 나온다 | E2E (슬라이스 1 흐름 연장) |

## 범위 제외

- 맛집 핀 표시/추가 (슬라이스 3)
- 현재 위치(geolocation) 이동
- 지도 종류 전환, 로드뷰 등 부가 기능
