# 슬라이스 15: 이름 바꾸기 + 다른 이름으로 접속

> 상태: 구현 완료 (단위·통합 78 + E2E 28 통과, 수동 검증 완료)
> 배경: 사용자 피드백 — "이름을 잘못 입력하면 고칠 방법이 없다"

## 동작 규칙

1. **배지 탭** → 메뉴: "이름 바꾸기" / "다른 이름으로 접속".
2. **이름 바꾸기**: 현재 계정의 이름만 수정 (핀·색상·id 유지).
   - 유효성은 가입과 동일 (trim 후 1~12자).
   - 이미 있는 이름이면 거부 ("이미 사용 중인 이름이에요") — 이어쓰기와 혼동 방지.
   - 성공 시 배지·내 핀 작성자 표시 즉시 갱신 (places 재조회).
3. **다른 이름으로 접속**: 세션(localStorage) 초기화 → 이름 입력 화면.
   기존 이름 입력 시 그 계정으로 복귀 (기존 이어쓰기 규칙).
