# 슬라이스 13: 맛집 목록 보기

> 상태: 구현 완료 (단위 75 + E2E 22 통과, 수동 검증 완료)
> 배경: 지도 탐색 보완 — 전체 핀을 리스트로 훑고 탭해서 이동

## 동작 규칙

1. 지도 좌하단 **"☰ 목록"** 버튼 → 바텀 시트(드래그 핸들 재사용)에 핀 리스트.
2. 행: 작성자 색 점 · 가게명 · 별점(★) · 작성자 이름.
3. **정렬 토글**: 최신순(기본) / 별점순. 별점 동률이면 최신순.
4. **친구 필터 연동**: 필터 활성 시 그 친구 핀만 목록에.
5. 행 탭 → 시트 닫힘 + 지도 그 핀으로 이동 + 정보 카드 오픈.
