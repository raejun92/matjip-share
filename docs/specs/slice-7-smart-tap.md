# 슬라이스 7: 스마트 탭 (가게 바로 제안 + 선택 시 지도 이동)

> 상태: 구현 완료 (단위 61 + E2E 16 통과, 수동 검증 완료)
> 배경: 사용자 피드백 — "지도에서 가게를 바로 선택하고 싶다. 가게 탭과 빈 곳 탭의 동작을 명확히 정의하자."

## 목표

지도에서 **가게(라벨)를 탭하면 그 가게를 바로 등록**할 수 있고,
**빈 곳을 탭하면 주변 목록**이 뜬다. 목록·검색에서 가게를 고르면 **지도가 그 위치로 이동**해
맞는 집인지 눈으로 확인할 수 있다.

## 동작 규칙 (탭 분기 — 상충 해소)

카카오 웹 SDK는 POI 탭 이벤트를 제공하지 않으므로 **거리 임계값 하나로** 분기한다:

1. 지도 탭 → 즉시 주변 검색 시작. popover는 "주변 확인 중…" 표시.
2. **최근접 가게가 30m 이내** → popover: **"📍 {가게이름} 추가하기"** + "주변 더 보기"
   - "추가하기" → 지도 그 가게로 이동 + 별점 화면 바로 진입
3. **30m 이내 가게 없음** → popover: "📍 이 위치 주변에서 찾기" (기존)
4. **선택 미리보기**: 주변 목록/검색 결과에서 가게 선택 시 지도를 그 좌표로 panTo.
5. fit bounds는 **최초 로드 시 1회만** — 실시간으로 친구 핀이 와도 화면을 끌고 가지 않는다.

## 인수 기준 (Acceptance Criteria)

| # | 기준 | 검증 방법 |
|---|------|----------|
| AC1 | 최근접 후보가 임계값 이내면 그 후보를, 아니면 null을 반환 | 단위 (TDD) |
| AC2 | 가게 근접 탭 → "{이름} 추가하기" → 별점 → 저장 | E2E(관대) + 수동 |
| AC3 | 목록/검색 선택 시 지도가 해당 좌표로 이동 | 수동 검증 |
| AC4 | 기존 흐름(주변 목록·직접 입력·검색 추가) 회귀 없음 | E2E |
