# 슬라이스 11: 핀 탭 우선 (친구 핀 보기 개선)

> 상태: 구현 완료 (단위 72 + E2E 20 통과, 수동 검증 완료)
> 배경: 사용자 피드백 — "다른 사람 핀을 클릭하면 내 핀 생성밖에 안 된다"

## 원인

1. 핀 탭 영역(32×40px)이 작아 모바일에서 빗나가기 쉽고, 빗나가면 스마트 탭이
   "그 가게 추가하기"를 띄워 "핀 탭 = 생성"처럼 보임.
2. CustomOverlay에 `clickable` 미설정 → 터치에서 핀 탭이 지도 탭 이벤트와 겹쳐
   정보 카드가 열리자마자 추가 popover로 덮일 수 있음.

## 동작 규칙

1. 핀 오버레이 `clickable: true` — 핀 탭 시 지도 탭 이벤트 미발화 (카카오 공식 옵션).
2. **지도 탭 지점이 화면 기준 30px 내에 저장된 핀이 있으면** 추가 흐름 대신
   **그 핀의 정보 카드**를 연다 (가장 가까운 핀). 필터 중엔 보이는 핀만 대상.
3. 30px 내 핀이 없으면 기존 스마트 탭 흐름 그대로.
4. 같은 가게를 또 저장하고 싶으면 검색으로 추가 가능 (기존과 동일).
