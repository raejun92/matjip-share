# 슬라이스 9: 바텀 시트 드래그 핸들

> 상태: 구현 완료 (단위 65 + E2E 18 통과, 수동 검증 완료)
> 배경: 사용자 피드백 — "주변 가게 시트 높이를 위아래로 조절하고 싶다"

## 동작 규칙

1. 주변 가게·맛집 추가(검색) 시트 상단에 **드래그 핸들(grabber)** 표시.
2. 핸들을 끌면 시트 최대 높이가 실시간으로 따라온다.
3. 놓으면 **스냅**: 45%(기본) 또는 85% 중 가까운 쪽. 30% 미만까지 내리면 **닫힘**.
4. 터치·마우스 모두 동작 (Pointer Events).

## 인수 기준

| # | 기준 | 검증 방법 |
|---|------|----------|
| AC1 | 놓은 위치에 따라 close/45%/85%로 스냅 판정 | 단위 (TDD) |
| AC2 | 핸들을 위로 끌면 시트가 커진다 | E2E |
| AC3 | 핸들을 바닥까지 끌면 시트가 닫힌다 | E2E |
