# 슬라이스 6: 위치로 맛집 추가

> 상태: 구현 완료 (단위 55 + E2E 15 통과, 수동 검증 완료)
> 배경: 사용자 피드백 — "이름은 모르고 위치만 알 때 어떻게 추가하나?"

## 목표

지도의 한 지점을 **탭(클릭)** 하면 그 주변 음식점·카페 목록이 거리순으로 떠서 고를 수 있다.
목록에 없는 가게는 **이름 직접 입력**으로 그 자리에 저장할 수 있다.

## 사용자 스토리

- 나는 지도에서 "그 골목 그 집" 위치를 탭해서 주변 가게 목록 중에서 고를 수 있다.
- 나는 카카오에 없는 새 가게도 이름만 쳐서 그 위치에 저장할 수 있다.
- 잘못 탭했으면 쉽게 취소할 수 있다.

## 동작 규칙

1. **지점 선택**: 지도 빈 곳 탭 → 회색 임시 마커 + "이 위치 주변에서 찾기" popover 표시.
   다시 지도를 탭하면 지점 이동, ✕ 또는 시트 닫기로 취소. 열려 있던 정보 카드는 닫힘.
2. **주변 검색**: popover 탭 → 카카오 카테고리 검색(음식점 FD6 + 카페 CE7, 반경 300m, 거리순)
   결과를 시트에 목록으로. **REST 키 보호를 위해 API 라우트(`/api/nearby-places`) 경유.**
3. **목록 선택**: 항목 탭 → 기존과 동일한 별점 → 저장 흐름 (가게의 실제 좌표·주소 사용).
4. **직접 입력**: 목록 하단 "찾는 가게가 없어요? 직접 입력" → 이름(1~100자) + 별점 → 저장.
   좌표는 탭한 지점, 주소는 카카오 좌표→주소 변환(coord2address) 결과.
5. **중복 병합**: FD6/CE7 두 결과를 kakaoId로 dedupe 후 거리순 정렬, 최대 15개.

## 인수 기준 (Acceptance Criteria)

|---|------|----------|
| AC1 | 두 카테고리 결과가 kakaoId dedupe + 거리순 정렬로 병합된다 | 단위 (TDD) |
| AC2 | 지도 탭 → popover → 주변 목록 표시 | E2E |
| AC3 | 목록에서 선택 → 별점 → 저장 → 내 색 핀 | E2E |
