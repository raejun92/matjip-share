# 슬라이스 10: 친구 필터 칩

> 상태: 구현 완료 (단위 68 + E2E 19 통과, 수동 검증 완료)
> 배경: 사용자 피드백 — "특정 친구가 어디 찍었는지 돌아다니며 찾아야 하나?"

## 동작 규칙

1. 지도 상단(내 배지 아래)에 **핀을 가진 멤버들의 색 칩** 가로 나열 (넘치면 가로 스크롤).
2. 칩 탭 → **그 친구 핀만 표시** + 그 핀들이 다 보이게 **화면 자동 맞춤**.
3. 활성 칩 다시 탭 → 전체 보기 복귀 (전체 핀 화면 맞춤).
4. 필터 중 열려 있던 정보 카드는 닫는다. 실시간 신규 핀에도 필터가 그대로 적용된다.

## 인수 기준

| # | 기준 | 검증 방법 |
|---|------|----------|
| AC1 | 핀 목록에서 중복 없는 작성자 목록 추출 (첫 등장 순) | 단위 (TDD) |
| AC2 | 칩 탭 → 그 친구 핀만 지도에 렌더링 + 화면 맞춤 | E2E |
| AC3 | 다시 탭 → 전체 핀 복귀 | E2E |
