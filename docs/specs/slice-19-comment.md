# 슬라이스 19: 한줄평

> 상태: 구현 완료 (단위·통합 79 + E2E 33 통과)
> 배경: 친구 피드백 — "코멘트를 쓰고 싶다". 댓글 스레드는 다음 후보 (반응 보고 결정).

## 동작 규칙

1. 핀에 **작성자의 한줄평(선택, 최대 200자)** 필드 추가.
2. **입력 위치**: 검색 추가·주변 추가·직접 입력의 별점 화면에 "한줄평 (선택)" 입력란.
3. **표시**: 정보 카드에 별점 아래 한줄평, 목록에도 한 줄로 표시.
4. **수정**: 내 핀 카드의 "별점 수정" → "수정"으로 확장 (별점 + 한줄평 함께).
5. 실시간 반영은 기존 UPDATE 재조회 흐름 그대로.
6. 마이그레이션은 additive(기본값 '') — 구버전 클라이언트 안전 (expand 패턴).

## 인수 기준

| # | 기준 | 검증 방법 |
|---|------|----------|
| AC1 | 한줄평 포함 저장·수정이 DB에 반영 | 통합 (로컬 Supabase) |
| AC2 | 추가 → 카드·목록에 한줄평 표시 | E2E |
| AC3 | 수정 → 카드 갱신 (친구 화면은 기존 실시간 흐름) | E2E |
