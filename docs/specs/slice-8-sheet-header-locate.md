# 슬라이스 8: 시트 헤더 고정 + 내 위치 버튼

> 상태: 구현 완료 (E2E 17 통과, 헤더 고정·내 위치 이동 수동 검증)
> 배경: 사용자 피드백 — "주변 가게 시트의 제목/닫기가 스크롤에 딸려 올라간다", "초기 위치가 어딘가?"

## 동작 규칙

1. **시트 헤더 고정**: 주변 가게 시트·맛집 추가(검색) 시트 모두, 목록이 스크롤돼도
   제목·닫기 버튼(검색 시트는 검색창까지)은 고정.
2. **내 위치 버튼**: 지도 우하단 ⌖ 버튼 → 브라우저 geolocation 권한 요청 → 현재 위치로 지도 이동.
   - 권한 거부/실패 시 안내 문구 잠깐 표시.
   - 초기 화면 규칙은 유지 (핀 전체 맞춤 → 없으면 서울시청). GPS는 버튼을 눌렀을 때만.

## 인수 기준

| # | 기준 | 검증 방법 |
|---|------|----------|
| AC1 | 주변/검색 시트에서 목록 스크롤 시 헤더 고정 | E2E + 수동 |
| AC2 | 내 위치 버튼 → (권한 허용 시) 지도 현재 위치로 이동 | E2E (모의 좌표) |
| AC3 | 권한 거부 시 오류 문구 표시 | 수동 |
