# 맛집공유 (matjip-share)

친구들끼리 맛집을 공유하는 웹앱.

## 컨셉

- 친한 친구 그룹 안에서만 맛집을 주고받는 **폐쇄형 공유** 서비스
- 불특정 다수 리뷰가 아니라, **내 친구가 실제로 추천한 곳**이라는 신뢰가 핵심

## 핵심 기능 (MVP 후보)

- [ ] 맛집 등록 (이름·위치·메모·사진)
- [ ] 지도에 핀 표시
- [ ] 장소 검색·자동완성
- [ ] 친구 그룹 / 폐쇄 공유
- [ ] 친구 초대 (링크 또는 코드)
- [ ] 평점·코멘트

## 기술 스택 (검토 중)

| 영역 | 후보 |
| --- | --- |
| 프론트엔드 | React / Next.js (웹앱) |
| 백엔드 | Supabase (인증 + DB + 스토리지) |
| 지도 | 카카오맵 API (1순위) / 네이버맵 API |
| 배포 | Vercel |

> 지도 API는 카카오맵으로 시작 예정 (무료 한도 + 진입장벽 낮음).
> 네이버맵은 카드 등록 필수·무료 티어 없음이라 추후 필요 시 교체 검토.

## 진행 메모

- 아이디어 타당성 검토 완료 → 기술적 걸림돌 없음, 입문~중급 난이도
- 다음 단계: 기능 정리 → 기술 스택 확정 → 코드 셋업
